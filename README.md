# 怪談じゃんけん(ローグライクサモンカードゲーム)

じゃんけんの手を持つカードで戦う、ブラウザで遊べるローグライクのカードゲームです。種族を選んでデッキを組み、5戦勝ち抜けば踏破です。

`index.html` をブラウザで開くだけで遊べます。

## クレジット

- キャラクターのドット絵：[Rド](http://rpgdot3319.g1.xrea.com/) 様のフリー素材を使用しています

ドット絵の著作権は素材の制作者に帰属します。このリポジトリに含まれる画像を、素材として抜き出して再配布・転用することはできません。素材を使いたい場合は、配布元から入手して配布元の規約に従ってください。
